# cli

CLI is not just a mode. It's a way how you can interact with the application. You can run webserver, config the
application, ask some data, create new entities, invite users etc.

Main commands:

- `serve` - run webserver. Can run in embed mode or not
- `config` - add various application config ( database, admin user, log path etc )
- `help` - show documentation text ( see `feature-ideas.md` )
